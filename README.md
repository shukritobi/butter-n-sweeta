# Butter n' Sweeta

Self-contained mobile-first catalogue and direct order-request website for **Butter n' Sweeta**, Puncak Alam.

## Current build

- no third-party ordering-page redirect
- local SVG placeholder artwork stored inside this repository
- responsive cookie catalogue
- cart-style order builder
- direct order request handoff to Butter n' Sweeta via WhatsApp
- GitHub Pages deployment workflow
- no external font, CSS, JavaScript or image dependencies

The placeholder artwork can be replaced with final product photography later without changing the catalogue or order flow.
